# Website sandbox

This folder contains a self-contained portfolio website prototype.

## Open or publish

- Source: [docs/index.html](./index.html)
- Quick preview: open `index.html` in a browser.
- GitHub Pages: in **Settings → Pages**, choose **Deploy from a branch**, select `website-sandbox` and `/docs`, then save. This is optional and requires repository settings access. Check any existing Pages configuration first before changing it.
- This is a **test branch** of `jeffgrannis/rh`, not a new repository and not a change to `main`.

## Features

- Responsive one-page layout, using only HTML, CSS, and vanilla JavaScript
- Semantic headings, skip link, keyboard focus styles, reduced-motion support
- Filterable work examples and working light/dark theme control
- No tracking, build dependencies, third-party scripts, or contact form

## Review before public use

Content is a draft describing work patterns and explorations, rather than an endorsed or final professional biography. Verify case-study wording, add approved project links and articles, then consider moving the site to its own repository to use with grannis.com.
